##	Azure Functions

### O que é este serviço e qual é sua função principal?:
o Azure functions tem como função criar aplicativos robustos ultilizando pouca infraestrutura e pouco orçamento.	Podendo também ultilizar sua infraestrutura de nuvem para fornecer os recusos necessarios para manter a 	aplicaçãorodando e sempre atualizada.

### Por que ele foi escolhido para este projeto? Qual problema específico da CorpTech ele resolve?
O Azure Functions foi escolhido porque consegue resolver problemas de processamento eficiente e escalável. No casoda CorpTechele o azure Functions resolve o problema de lidar com grandes volumes de dados e tarefas repetitivas,garantindo que tudo seja processado rapidamente e apenas quando for necessário.

### Qual seria uma alternativa a este serviço? Por que a alternativa foi descartada?
Uma alternativa ao Azure Functions seria o AWS Lambda, da Amazon Web Services, mas ele foi descartado porque oprojeto já utiliza o ecossistema da Microsoft, o que acaba facilita a integração e também reduz a complexidade.

### por que usar funções serverless para a extração de dados?
Usar funções serverless facilita extração de dados porque o código só roda quando realmente for necessário, semprecisar manter servidores ligados o tempo todo. Isso reduz custos, já que você paga apenas pelo uso, e aindapermite que o sistema cresça automaticamente conforme a demanda.
